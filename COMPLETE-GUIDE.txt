📝 HOW TO UPDATE PROXIES (STEP BY STEP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: Using UPDATE-PROXIES.bat (EASIEST)
─────────────────────────────────────────────

1. Double-click "UPDATE-PROXIES.bat"
2. Notepad opens with proxies.json
3. Scroll to bottom, find last proxy line
4. Copy-paste this format for each new proxy:

   {"host": "IP_ADDRESS", "port": PORT, "username": "", "password": "", "country": "XX", "location": "Description"}

5. Add comma (,) after previous line!
6. Update "totalProxies" number at top
7. Save file (Ctrl+S), close Notepad
8. Press "Y" to restart bots with new proxies
9. Done! ✅


METHOD 2: Manual Edit (ADVANCED)
─────────────────────────────────

1. Open: proxies.json in Notepad
2. Find this section:

   "proxies": [
     {"host": "1.2.3.4", "port": 8080, ...},
     {"host": "5.6.7.8", "port": 9090, ...}   <-- Last line
   ]

3. Add comma after last line, add new proxies:

   "proxies": [
     {"host": "1.2.3.4", "port": 8080, ...},
     {"host": "5.6.7.8", "port": 9090, ...},   <-- Added comma!
     {"host": "10.20.30.40", "port": 3128, "username": "", "password": "", "country": "US", "location": "New York"}
   ]

4. Update "totalProxies": XX at top (increase the number)
5. Save file
6. Restart bots (or they auto-pickup on next session)
