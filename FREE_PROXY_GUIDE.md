## ❓ **TROUBLESHOOTING**

### "No working proxies found"
- Free proxies are unreliable
- Try running without proxies instead
- Re-run `npm run fetch-proxies` (different results each time)

### "Connection errors"
- Your IP might be rate-limited
- Try Cloudflare WARP
- Use airplane mode on/off to get new IP (mobile hotspot)

### "Low earnings"
- Run multiple instances (3-5)
- Ensure bot is clicking ads (check logs)
- Verify Adsterra account is active
