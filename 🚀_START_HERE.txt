🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Cannot find module 'puppeteer'"
SOLUTION: npm install puppeteer

PROBLEM: "Proxies not found"
SOLUTION: npm run setup-proxies

PROBLEM: Low page views (under 20/hr)
SOLUTION:

   2. Try turbo mode: npm run turbo

SOLUTION:
   1. Verify Adsterra ads showing on website
   2. Increase click rate in code (line 22)

PROBLEM: Bot crashes
SOLUTION:
   1. Update Node.js (need v16+)
   2. Restart: npm run bot
