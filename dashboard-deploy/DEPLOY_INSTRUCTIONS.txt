──────────────────────────

5. Click "Deploy site"
6. Done!

═══════════════════════════════════════════════════════════════
           📊 CONNECT YOUR BOT STATS (REQUIRED!)
═══════════════════════════════════════════════════════════════

After deployment, your dashboard needs data!

OPTION A: Use GitHub to Store Stats (Recommended)
──────────────────────────────────────────────────
1. Your bot saves stats to: bot-stats.json

2. Upload stats to GitHub:
   - Create a repo called "bot-stats"
   - Upload bot-stats.json file
   - Get the raw file URL:
     https://raw.githubusercontent.com/YOUR_USERNAME/bot-stats/main/bot-stats.json

3. In Netlify:
   - Go to: Site settings → Environment variables
   - Add variable:
     Key: GITHUB_STATS_URL
     Value: (paste the raw GitHub URL above)
   - Trigger redeploy

4. Run stats syncer on your computer:
   node sync-to-github.js
   (This auto-uploads stats every 60 seconds)

OPTION B: Use JSONBin.io (Free, No GitHub Needed)
──────────────────────────────────────────────────
1. Go to https://jsonbin.io
2. Sign up (free)
3. Create a new bin
4. Copy the bin URL
5. Add to Netlify environment variables:
   Key: GITHUB_STATS_URL
   Value: (your JSONBin URL)
6. Modify sync script to upload to JSONBin

OPTION C: Manual Upload (Testing)
──────────────────────────────────
For testing, you can manually upload bot-stats.json:
1. Copy your bot-stats.json
2. Upload to GitHub or any public file host
3. Use that URL in GITHUB_STATS_URL

═══════════════════════════════════════════════════════════════
                     🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEM: Dashboard shows all zeros
SOLUTION: 
  ✅ Add GITHUB_STATS_URL environment variable
  ✅ Make sure stats file is publicly accessible
  ✅ Run stats syncer: node sync-to-github.js
  ✅ Wait 60 seconds for sync

PROBLEM: "Failed to fetch stats" error
SOLUTION:
  ✅ Check GITHUB_STATS_URL is correct
  ✅ Make sure GitHub repo is public
  ✅ Test URL in browser - should show JSON
  ✅ Check browser console for CORS errors

PROBLEM: Functions not working
SOLUTION:
  ✅ Make sure netlify.toml exists
  ✅ Make sure netlify/functions folder exists
  ✅ Redeploy the site
  ✅ Check Netlify build logs
