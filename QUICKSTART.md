```bash
cd traffic-bot
npm install
```

---

## 🔑 Step 2: Get API Keys (5 minutes)

### Reddit (Easiest - 2 minutes)

1. Go to: https://www.reddit.com/prefs/apps
2. Click "create another app"
3. Fill in:
   - Name: `TrafficBot`
   - Type: Select **"script"**
   - Redirect: `http://localhost:8080`
4. Click "create app"
5. Copy the ID (under the name) and secret

### Twitter (Optional - 3 minutes)

1. Go to: https://developer.twitter.com/en/portal/dashboard
2. Create app (say it's for "content sharing")
3. Get: Bearer Token, API Key, API Secret, Access Tokens
4. Copy all tokens

### Pinterest (Optional - 3 minutes)

1. Go to: https://developers.pinterest.com/apps/
2. Create app
3. Generate Access Token with write permissions
4. Copy token

---

## ⚙️ Step 3: Configure (2 minutes)

```bash

```

Follow the wizard and paste your API keys!

## 🚀 Step 4: RUN IT! (1 minute)
